ACCOUNT SUPPORT

If a user forgets their password, they can reset it using the "Forgot Password" option on the login page.

If an account is locked, the user should wait for the account recovery process or contact customer support.

Users should never share their password with anyone.


PAYMENT SUPPORT

If a payment fails, first check whether the card has sufficient funds and whether the card details are correct.

If a payment is declined, the user should verify their card details or try another supported payment method.

A pending payment may take some time to complete. Users should avoid making duplicate payments while the original transaction is pending.


REFUND SUPPORT

Users can request a refund through customer support.

For a refund request, the user should provide the order or transaction details.

Refund processing time depends on the payment method and may take several business days.


TECHNICAL SUPPORT

If the application crashes, the user should restart the application and check whether an updated version is available.

If the website shows an error, the user should refresh the page and check their internet connection.

If the technical problem continues, the user should contact technical support and provide the error message.
